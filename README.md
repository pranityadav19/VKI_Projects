# VKI Internship Projects

This repository contains projects I worked on during my **Software Engineering Internship at VKI LLC**, where I focused on building data-driven solutions to optimize **supply chain, forecasting, and procurement processes**.  

---

## 📂 Project List

### 1. **End-to-End Supply Chain Process** (`SupplyChainE2E.pdf`)
- **Description**: Designed an end-to-end (E2E) supply chain workflow covering order creation, container management, and order completion.  
- **Highlights**:  
  - Modeled the full lifecycle: order placement, quality control, customs, and delivery.  
  - Captured scan-based trade payment flow (stores pay as products are sold).  
- **Skills**: Process Mapping, Workflow Design, Supply Chain Analytics.  

---

### 2. **Forecasting Data Model** (`ForecastingDataModel.pdf`)
- **Description**: Built a relational data model to support forecasting and demand planning.  
- **Highlights**:  
  - Designed entity relationships for **Products, Stores, Manufacturers, and Sales**.  
  - Incorporated lead time, cost price, and supplier-product relationships.  
- **Skills**: Data Modeling, ER Diagrams, SQL Schema Design.  

---

### 3. **Email Procurement Process** (`EmailProcurementProcess.pdf`)
- **Description**: Automated vendor email validation for procurement.  
- **Highlights**:  
  - Developed logic to verify, reject, or flag duplicate vendor emails.  
  - Created a flowchart-based process to handle vendor prioritization by cost.  
- **Skills**: Process Automation, Data Validation, Business Rules Design.  

---

### 4. **Email Procurement Data Model** (`EmailProcurementDataModel.pdf`)
- **Description**: Designed a relational database to store vendor emails and statuses.  
- **Highlights**:  
  - Created schema for vendors, emails, and archival process.  
  - Supported daily email ingestion and validation pipeline.  
- **Skills**: Database Schema Design, Data Integrity, Vendor Management.  

---

### 5. **Email Promotion Model** (`EmailPromotion.ipynb`)
- **Description**: Jupyter Notebook prototype for analyzing and validating promotional emails.  
- **Highlights**:  
  - Implemented email parsing, cleaning, and verification.  
  - Demonstrated logic for setting status codes (Verified, Rejected, Repeated).  
- **Skills**: Python, pandas, Data Cleaning, Notebook Prototyping.
